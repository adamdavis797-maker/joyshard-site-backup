# JoyShard website backup

Hosted on **UEESHOP** (store id UPBI981). Live site: https://joyshard.com

## What this repo contains
- `pages/` — rendered HTML snapshots of key storefront pages
- `custom-code/` — extracted custom fragments (e.g. design form) plus per-page notes
- `meta/` — source notes

## What this is NOT
Full UEESHOP platform PHP/theme source is not downloadable from the SaaS admin as a complete app tree. This backup preserves our custom storefront content and page snapshots for recovery/diff.

## Restore notes
Re-apply DIY custom-code modules via UEESHOP admin → 店铺 → DIY / 单页 → 自定义代码.
